# Morb Chat

A modern, real-time chat application built with HTML, CSS, and JavaScript.

## Features

✨ **User Authentication** - Secure login and registration
📱 **Responsive Design** - Works on desktop and mobile
💬 **Real-time Messaging** - Send and receive messages instantly
👥 **User Management** - Admin panel for user management
🎨 **Modern UI** - Beautiful dark theme with smooth animations
💾 **Local Storage** - Messages persist in browser

## Project Structure

```
morb.chat/

```

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Create an account or login
4. Start chatting!

## Technologies Used

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Storage**: Browser LocalStorage
- **Backend**: (Optional) Firebase or custom backend

## Usage

### Authentication
Users can register with a username, email, and password. Login is handled through the authentication module.

### Chat
The chat interface allows users to send and receive messages in real-time. Messages are stored locally in the browser.

### Admin Panel
Admins can manage users, view user status, and perform administrative tasks.
